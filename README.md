# StreamX — CCcam & IPTV Pro Hub

تمت إعادة تنظيم المشروع انطلاقاً من ملف cccam_iptv (v2).html إلى بنية modular مناسبة لـ GitHub Pages.

- src/pages/index.html: الواجهة الرئيسية.
- src/components/: المكونات المشتركة.
- src/styles/: الأنماط العامة والوضع الداكن وصفحات المقالات.
- src/lib/: وظائف البحث وSEO وواجهة JavaScript.
- src/content/blog/: محتوى المقالات.
- src/Legal pages/: الصفحات القانونية.
- public/: الموارد العامة وrobots وsitemap.

البيانات المولدة في الواجهة تجريبية. يجب استخدام أي مصادر بث وفق حقوق المحتوى والقوانين وشروط مزود الخدمة.
