خطوات التحقق

  1. راجع README ووصف المشروع والجهة المالكة للمستودع.
  2. تحقق من ملف الترخيص وشروط استخدام المحتوى.
  3. راجع تاريخ التحديث وحالة الروابط.
  4. تجنب أي رابط يطلب تجاوز حماية أو الحصول على وصول غير مصرح به.
