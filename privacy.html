سياسة الخصوصية

تحترم StreamX خصوصية الزوار. الإصدار الحالي لا يتطلب إنشاء حساب ولا يجمع نموذجاً مركزياً لبيانات المستخدم داخل الموقع.

التخزين المحلي

قد يستخدم الموقع localStorage لحفظ تفضيل واجهة مثل الوضع الفاتح أو الداكن. هذه البيانات تبقى في متصفحك ولا تُرسل إلى خادم StreamX.

الخدمات الخارجية

قد يعتمد الموقع على موارد خارجية مثل Google Fonts وHLS.js ومصادر معاينة عامة. يخضع الاتصال بهذه الخدمات لسياسات الخصوصية الخاصة بمزوديها.

GitHub Pages

الموقع مستضاف عبر GitHub Pages. توضح GitHub أن زيارة مواقع Pages قد تتضمن تسجيل عنوان IP لأغراض أمنية وفق ممارسات GitHub للخصوصية.

ملفات تعريف الارتباط

لا يعتمد الإصدار الحالي على ملفات تعريف ارتباط للإعلانات أو الحسابات. إذا تمت إضافة خدمات تحليل أو إعلانات مستقبلاً، يجب تحديث هذه السياسة وآلية الموافقة بما يتناسب معها.

التواصل

عند فتح Issue على GitHub، تصبح المعلومات التي تختار نشرها خاضعة لمنصة GitHub وسياساتها. لا تنشر بيانات حساسة.
